## Implementation notes

- Auth/session: logout now preserves the last successful browser choice, signed-out auth status tries to refresh from that stored browser, and the login sheet reorders browser buttons so the last-used browser comes first.
- Toolbar identity: authenticated browse responses now extract the topbar avatar URL from YouTube and the toolbar uses that image instead of the generic profile glyph.
- Search/navigation: suggestion clicks now survive the search-field focus teardown, and opening a search result suspends the results page instead of destroying it so back/forward returns to the real results screen.
- History/recommendations copy: the signed-out recommendation fallback now explicitly says the user is logged out instead of incorrectly implying history is disabled.
- Watch-time accuracy: local research against YouTube’s watch tracking payload and `yt-dlp`’s `_mark_watched` path confirmed that `videostatsWatchtimeUrl` is driven by `cpn`, `cmt`, `st`, and `et` query parameters. SwiftTube was overcounting because big seek jumps were being reported as if they were contiguous watched segments. The fix now:
  - skips periodic sync reports while playback is paused or scrubbing
  - tracks contiguous watched ranges instead of trusting raw playhead jumps
  - flushes watchtime in bounded chunks and resets the pending segment when a seek discontinuity is detected
  - keeps the initial playback ping separate from watchtime segment flushing
- Player/sidebar: theater mode now uses the same immersive side-panel behavior as fullscreen, the sidebar toggle moved to the top-right overlay and only appears in immersive layouts, the standard next-up rail is independently scrollable again, and the standard stacked watch layout lets the player widen instead of leaving a dead gap.
- Playlist sidebar: playlist queue, suggestions, and live chat now share the same tab model. Playlist playback in a playlist can show playlist/suggestions, and live videos inside playlists can expose playlist/suggestions/live chat in one place.
- Playlist pages: the library page now hides `Liked Videos` and `Watch Later`, the left padding is slightly loosened, and the playlist detail header reuses the playlist’s actual playlist artwork/icon instead of stealing the first video thumbnail.
- Subtitles: subtitle tracks are normalized and deduplicated before display, with manual tracks preferred over autogenerated duplicates and cleaned-up display labels.
- Menus/hit targets: settings submenus and save-to-playlist sizing were tightened to reduce the blank “iMac chin” space, and row hit targets were widened across secondary tabs and popover menu rows.
- Player polish: the uploaded pill toggles between exact and relative time, theater/hold-speed icons use the requested symbols, the destructive history context menu uses a proper destructive `Label`, and paused video surface resizes now trigger a debounced same-time MPV reload to correct stretched held frames.

## Final report

- Auth/session work landed in `YouTubeAuth`, `SwiftTubeBackend`, `Models`, `ContentView`, and related auth UI wiring. Last-used browser choice now survives logout, silent revalidation tries that browser first, and the authenticated toolbar avatar now comes from YouTube’s own topbar avatar payload.
- Search/history/navigation fixes landed in `ContentView` and `ViewModels`. Suggestion clicks now submit instead of dying during focus teardown, search results are suspended/resumed instead of discarded when opening videos or channels, and back/forward navigation restores the actual search-results route.
- Watch-page/player work landed mostly in `PlayerView`, `PlayerPlaybackCoordinator`, and `VideoContextMenuContent`. Theater mode now shares the immersive overlay/sidebar behavior with fullscreen, the sidebar toggle moved to the top-right immersive chrome, the uploaded stat pill toggles exact/relative time, popover/menu hit targets are wider, affected popovers were resized to reduce bottom dead space, the requested icons were updated, and destructive history removal styling is back.
- Sidebar/playlist fixes landed in `PlayerView` and `ContentView`. The next-up rail is scrollable again, playlist/suggestions/live-chat now share one tab model, the playlist library hides `Liked Videos` and `Watch Later`, left padding was loosened on the playlists library page, and playlist detail pages now reuse the playlist’s real artwork/icon rather than the first video thumbnail.
- Watch-time and subtitles fixes landed in `SwiftTubeBackend`, `PlayerView`, and `PlayerPlaybackCoordinator`. Watch sync now reports only active watched ranges instead of seek jumps, and subtitle normalization/deduplication now prefers cleaner/manual entries before the menu is built.
- Repo-size investigation result: the 4.6GB+ working directory is not normal SwiftUI source size. The dominant space usage is local SwiftPM build output under `SwiftTubeApp/.build`, especially `index-build`, `debug`, and binary artifact caches such as `mpvkit`.
